# Frizzy's Tesla Links

Your survival kit for the Tesla Wait Club. A single-page replacement for [lnk.bio/TeslaLinks](https://lnk.bio/TeslaLinks), with delivery trackers, ship tracking, Southampton webcams, community chats, a tracking guide and FAQs.

Everything lives in `index.html`: no build step and no dependencies. To edit a link, find it in `index.html` and change the `href` and text. Any static host can serve it, including Vercel and GitHub Pages.
